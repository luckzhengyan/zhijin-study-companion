## 🚀 三大引擎

| 引擎 | 功能 | 一句话概括 |
|------|------|-----------|
| 🃏 卡片引擎 | 将知识拆解为最小记忆单元 | 一段文字 → 带记忆锚点的双向验证卡片 |
| 📖 故事引擎 | 将零散知识点编织为因果叙事 | 用"因为-所以"链条串联碎片，情绪锚点加深印象 |
| 🔍 追问引擎 | 5层递进追问直击认知盲区 | 从"复述"到"迁移"，逐层检验你是否真正理解 |

## 🎯 使用示例

### 卡片引擎
```
帮我把细胞膜的结构拆成记忆卡片
```
→ 自动生成5张带记忆锚点和复习间隔的卡片

### 故事引擎
```
帮我把这些经济学术语串联一下
```
→ 用因果叙事链将零散概念串联成可记忆的故事

### 追问引擎
```
我好像懂了边际成本
```
→ 从L1复述到L5迁移，逐层追问直到真正理解
